# public/ — Static Assets

- **`favicon.svg`** — SVG favicon for the site. Referenced in `index.html` head.
- **`manifest.json`** — Web app manifest for PWA support. Referenced in `index.html` head.
- **`rss.xml`** — Auto-generated RSS feed for blog posts. Generated by `scripts/generate-rss.ts` during build. Referenced in `index.html` head.
- **`my_cv_v1.5.pdf`** — Downloadable CV file. Linked from the Home page hero section.
- **`simple_extract.py`** — Standalone Python script for text extraction (accessible at `/personal_garden/simple_extract.py`).

Sub-directories: `anki/`, `games/`, `resources/`, `scripts/` for downloadable assets.

Connects to: `scripts/` (RSS generation), `index.html` (SEO and PWA links), `src/pages/Home.tsx` (CV download).
