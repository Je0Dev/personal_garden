# public/scripts/ — Downloadable Python Scripts

- **`build_anki_decks.py`** — Python script for building Anki deck packages from source data. Used by language learning workflow.
- **`organize_vocab.py`** — Vocabulary organization and formatting utility for language learning materials.
- **`radicals_org.py`** — Chinese radical organization tool for creating structured character study materials.
- **`s1.py`** — Utility script for language data processing.

Connects to: `src/data/languageScripts.ts` (script metadata and code previews), `src/components/languages/ScriptModal.tsx` (viewer/download UI).
