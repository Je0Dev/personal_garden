# src/components/tags/ — Tag Components

- **`PostCard.tsx`** — Card for a tagged blog post showing title, excerpt, tags, and publish date. Rendered in the Tags page.
- **`TagFilter.tsx`** — Tag filter bar that highlights active tags and shows post counts per tag. Filters posts on click.

Connects to: `src/pages/Tags.tsx` (parent), `src/data/posts.ts` (post content), `src/data/tag-colors.ts` (color mapping).
