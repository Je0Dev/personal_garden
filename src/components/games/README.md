# src/components/games/ — Game Components

- **`GameDetailModal.tsx`** — Full-screen modal for published games showing features, tech stack, syntax-highlighted code walkthrough, and a play button. Triggered from game cards.
- **`GameUpcomingModal.tsx`** — Modal for upcoming game previews with countdown timer, planned features, tech stack, and code snippet. Triggered from "sneak peek" cards.

Connects to: `src/pages/Games.tsx` (parent), `src/data/games.ts` (game data).
