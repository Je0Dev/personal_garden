# src/components/projects/ — Project Components

- **`ProjectCard.tsx`** — Grid card for each project showing title, description, tech tags, and thumbnail. Rendered in the Projects page grid.
- **`ProjectFilter.tsx`** — Tag-based filter bar for the project grid. Clicking a tag filters visible projects.
- **`ProjectModal.tsx`** — Full detail modal for projects: description, tech stack, links, syntax-highlighted code walkthrough.

Connects to: `src/pages/Projects.tsx` (parent), `src/data/projects.ts` (project data).
